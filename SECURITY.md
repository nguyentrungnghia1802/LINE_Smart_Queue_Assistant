# Security Policy

## Supported Versions

The following versions are currently supported with security updates:

| Version | Supported |
| ------- | --------- |
| 5.1.x   | ✅         |
| 5.0.x   | ❌         |
| 4.0.x   | ✅         |
| < 4.0   | ❌         |

We recommend using a supported version to ensure that you receive the latest security fixes and updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately rather than opening a public issue.

When submitting a report, please include:

* A clear description of the vulnerability
* Steps to reproduce the issue
* The affected version(s)
* The potential impact
* Any relevant logs, screenshots, or proof-of-concept details

We will acknowledge your report within **3 business days** and provide updates as we investigate the issue.

If the vulnerability is confirmed, we will work on a fix and coordinate the disclosure when appropriate. If the report is declined, we will provide an explanation whenever possible.

Please do not publicly disclose the vulnerability until a fix has been released or disclosure has been coordinated with the maintainers.

Thank you for helping keep this project and its users secure.
